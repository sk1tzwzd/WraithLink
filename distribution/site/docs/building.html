Building

The public git repo is the toolkit (scripts, overlays, apps). GrapheneOS source is synced with repo on a build host — typically 32 GiB+ RAM, hundreds of GB disk.

Pixel / GrapheneOS pipeline

cp config/wraithlink.conf.example config/wraithlink.conf
# edit WL_DEVICE (tokay|akita), WL_DOMAIN, paths
bash scripts/00-setup-build-env.sh
bash scripts/01-sync-source.sh
bash scripts/02-extract-vendor.sh
bash scripts/03-gen-keys.sh          # backup keys offline
bash scripts/04-apply-rebrand.sh
bash scripts/05-build.sh
bash scripts/06-generate-release.sh YYYYMMDDNN
bash scripts/07-deploy-site.sh

Keys

Encrypted under keys/<device>/. Back up with passphrase offline before any flash. See repo docs/keys-backup.md.

Never put signing keys under the public web root (/srv).
