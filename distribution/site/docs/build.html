Build from source

This repository is the toolkit. GrapheneOS/AOSP is synced with repo during the build.

Host requirements

  • x86_64 Linux (Debian 12 / Ubuntu 24.04+)
  • 32 GiB RAM minimum (64 GiB+ recommended)
  • ~250 GiB+ free disk for one device tree + out/

Pixel / GrapheneOS pipeline

cp config/wraithlink.conf.example config/wraithlink.conf
# edit WL_DEVICE, WL_DOMAIN, paths…

bash scripts/00-setup-build-env.sh
bash scripts/01-sync-source.sh
bash scripts/02-extract-vendor.sh
bash scripts/03-gen-keys.sh
bash scripts/04-apply-rebrand.sh
bash scripts/05-build.sh
bash scripts/06-generate-release.sh YYYYMMDDNN   # password= for decrypt-keys
bash scripts/07-deploy-site.sh

Decoy milestone

Use config/wraithlink-decoy.conf (WL_ENABLE_DECOY_DURESS=true), then scripts/decoy-preflight.sh before signing. Hardware QA checklist in the repo under docs/duress.md.
