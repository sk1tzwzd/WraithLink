OTA & updates

WraithLink uses the GrapheneOS Updater pointed at https://ota.wraithlink.com (configurable at build time via WL_OTA_URL).

Channels

Release metadata files such as tokay-stable / akita-stable live on the OTA host. Factory images for the web installer live under https://releases.wraithlink.com/<build>/.

Operator deploy

bash scripts/07-deploy-site.sh

Publishes the site, copies the latest signed factory zip + OTA package, and updates install/release.json (merges per-device entries).

User side

Settings → System → Update (or the Updater app). Updates install in the background with A/B seamless reboot when ready. Never sideload random zips from third parties.
