Feature tour

What the first WraithLink release includes on top of GrapheneOS, and what is still milestone work.

Coercion resistance (v1)

  • Panic wipe — GrapheneOS's key-destroying duress credential, surfaced in Setup. Details.
  • WraithVault — a secondary user profile for sensitive apps/data. Create and back it up from Setup; it is not hidden from the system UI.
  • Decoy PIN — Milestone 2: unlocks the everyday phone while silently destroying WraithVault. Not in lean published images until hardware QA. Not a panic-wipe replacement and not deniable storage.

At-rest hardening

  • Auto-reboot and auto-wipe — configure via Setup → Settings.
  • USB data blocked while locked (allowed when unlocked for backups).
  • Media metadata strip — EXIF/GPS/device tags removed when media is indexed.

Network privacy

  • Encrypted DNS — one-tap Mullvad DoT in Setup (not forced at first boot).
  • Per-connection MAC randomization — GrapheneOS default.
  • Disable 2G — guided into mobile network settings.
  • Install Orbot / Tor Browser / Mullvad VPN from F-Droid when you need them.

Communication

  • WraithLink messenger — E2EE, P2P over Tor, disappearing messages, mandatory verification. Details.

Companion desktop

  • X47 pairing — one phone to one desktop over an authorized onion service. Details.

Preinstalled apps

  • F-Droid (and Setup; Chat when the build stages successfully).
  • Sandboxed Google Play remains an optional first-run offer — not shipped in the image.

Guided setup

The WraithLink Setup wizard sets safe defaults and walks through the steps above. It is guided but entirely skippable.
