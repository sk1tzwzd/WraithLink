Security model

Signing keys

Each device codename has encrypted keys under keys/<device>/ (AVB, release, platform, media, …). Generated by scripts/03-gen-keys.sh.

Backup (do this first)

  1. Copy keys/tokay and keys/akita offline (encrypted USB / air-gapped store).
  2. Store the key passphrase separately from the key files.
  3. Never put keys under /srv or any public web root.

Signing

script/generate-release.sh decrypts keys via password= env (or interactive prompt), signs target files, and writes factory + OTA zips under releases/<build>/.

Loss = bricks updates

If you lose device keys, you cannot ship OTAs that verified-boot will accept on already-flashed phones. Backup before anything else.
