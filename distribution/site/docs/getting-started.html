Getting started

End-to-end path from a stock Pixel to a hardened WraithLink device.

1. Confirm hardware

You need a Pixel 9 (tokay) or Pixel 8a (akita). Other Pixels can be built later; non-Pixels should use WraithLink Lineage (weaker security).

2. Back up

Flashing erases the device. Export anything you need before OEM unlock.

3. Flash

Use the web installer (Chromium + WebUSB) or fastboot with the factory zip. Full steps: Install guide.

4. First boot — Setup

  1. Set a strong screen lock (long PIN or passphrase).
  2. Set the panic wipe credential (GrapheneOS duress) — different from your unlock PIN.
  3. Enable USB-blocked-while-locked, auto-reboot / auto-wipe as you prefer.
  4. Disable 2G per SIM.
  5. Optional: one-tap Mullvad encrypted DNS.
  6. Optional: create WraithVault and back it up off-phone.

5. Apps

F-Droid is preinstalled. Add Orbot, Tor Browser, Mullvad VPN from there. Sandboxed Play is an optional GrapheneOS offer — not forced.

6. Messenger

Open WraithLink Messenger, create identity, verify contacts with the short code before chatting. See Messenger.

Decoy PIN

Builds with ro.wraithlink.decoy=1 can arm a coercion PIN that drops the vault. Confirm backup in Setup first. See Duress & WraithVault.
