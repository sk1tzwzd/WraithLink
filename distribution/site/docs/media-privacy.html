Media privacy

When MediaProvider indexes an image or video (camera, download, message, USB copy), WraithLink strips sensitive metadata by default.

What is removed

  • GPS / location EXIF
  • Device make/model and serial-like tags
  • Capture timestamps (where applicable)
  • Common XMP location packets on supported formats

Control

Settings.Secure wraithlink_strip_media_metadata: 1 = strip (default), 0 = leave metadata intact. Setup enables the default on first boot.

What GrapheneOS already does

Camera can strip EXIF and disable geo tagging in its own settings. WraithLink’s strip covers media that arrives from other apps too — not only the stock camera.

Limit

Share-time PDF stripping and exotic containers are not guaranteed. Re-check critical files before publishing.
