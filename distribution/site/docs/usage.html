Daily use

First boot: the setup wizard

After you flash and boot WraithLink, it applies safe defaults and then offers WraithLink Setup. Every step is optional — skip and return later from the app icon. Typical order:

  1. A strong screen lock (the root of your disk encryption).
  2. The panic (duress wipe) credential.
  3. Auto-reboot and auto-wipe.
  4. Blocking USB while locked.
  5. Disabling 2G.
  6. Optional Mullvad encrypted DNS.
  7. Creating WraithVault (secondary profile).
  8. Backing WraithVault up (reminder — not a hard gate).
  9. Apps via F-Droid; optional sandboxed Google Play.

Credentials in v1

Use your normal PIN every day. Memorise a distinct panic credential. A decoy-duress PIN that destroys the vault while opening the phone is not in the first release — see Duress & WraithVault.

Using WraithVault

Switch into WraithVault the way you switch Android user profiles, give it its own strong lock, and put sensitive apps there. Back it up regularly to X47 or an encrypted USB-C drive.

Apps and updates

Install open-source apps from F-Droid. System updates arrive over the air from WraithLink's own OTA server; reboot when prompted.

Tor / VPN

Install Orbot, Tor Browser, or Mullvad VPN from F-Droid when you need them. There is no automatic Tor-only "Ghost" profile in v1.

If a network won't connect

Strict encrypted DNS can block captive-portal Wi-Fi. Turn Private DNS off briefly in Settings, complete the login page, then turn it back on. See network privacy.
