Network privacy

What v1 actually configures, versus what you install yourself.

Encrypted DNS

WraithLink Setup offers one-tap DNS-over-TLS to Mullvad (dns.mullvad.net). It is not forced before first network bring-up, so captive portals remain usable. You can point Private DNS at any DoT provider, or turn it off briefly to sign in on public Wi-Fi.

Per-connection MAC randomization

Inherited from GrapheneOS: a fresh random MAC per Wi-Fi network. WraithLink does not ship a separate MAC overlay in v1.

Disable 2G

Setup deep-links into mobile network settings so you can turn 2G off and blunt IMSI-catcher downgrade attacks.

Tor and VPN apps

Orbot, Tor Browser, and Mullvad VPN are not preinstalled in the lean v1 image. Install them from F-Droid when you need them. The messenger and X47 pairing use Tor onion services once Tor is available on the device.

Not in v1

An automated Tor-only "Ghost" profile and a bundled dnscrypt-proxy service are milestone work — do not expect them in the first factory image.
