Supported devices

WraithLink runs on Google Pixel phones only. The first published images target two devices; the same pipeline can build other GrapheneOS Pixels later.

DeviceCodenameStatus
Pixel 9tokayv1 reference / factory images
Pixel 8aakitav1 second ship target

Why Pixel-only

  • A relockable bootloader that accepts a custom key — verified boot after install.
  • A dedicated secure element — real key-destroying panic wipe.
  • Prompt firmware support — monthly patches WraithLink can ship.

What you lose on other hardware

Without custom-key verified boot or a secure element, the panic wipe and integrity model stop being trustworthy. We would rather support fewer devices properly.
