Lineage

Wider device support with a weaker boot story. Prebuilt Lineage ROMs are no longer hosted here — build from the public toolkit. The messenger APK still works on any Android 14+ phone.

Build from GitHub Messenger APK

Self-host only

Server capacity is reserved for Pixel WraithLink images and the messenger. Lineage edition tooling lives in the repo under lineage/ — sync, stage, brunch, and publish on your own hardware.

Security ceiling

Unlocked bootloaders and software wipe only — not GrapheneOS SE key destroy. Prefer the Pixel edition when that matters. Details in Lineage docs.
