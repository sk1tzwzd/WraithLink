Security model — Lineage edition

Weaker than Pixel WraithLink. This edition trades GrapheneOS-grade boot integrity for device coverage. Read this before trusting it with anything important.

You get

  • Android disk encryption (device baseline)
  • WraithLink messenger — E2EE over Tor, no message server (same app as Pixel)
  • Optional WraithVault secondary user
  • Soft panic — wipeData() factory reset via device admin

You do not get

  • Bootloader relock to your own AVB key (most phones stay unlocked)
  • Titan / SE key-destroying duress
  • GrapheneOS exploit-mitigation baseline
  • Decoy PIN (not in Lineage v1)

For coercion / forensics where verified boot and SE duress matter, use Pixel WraithLink.
