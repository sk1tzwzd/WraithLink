Messenger

E2EE peer-to-peer over Tor. No accounts, no phone number, no server. Works on any Android 14+ phone — stock, WraithLink Pixel, or Lineage.

Download APK How it works

Install

Sideload on the phone (Chrome → allow unknown apps for the browser).

  1. Download WraithLinkChat.apk.
  2. Open the file and install.
  3. Tor is embedded in the app (Orbot is optional, not required).
  4. Add contacts by scanning a QR or pasting their identity JSON, then confirm the short verification code before chatting.

SHA-256: see WraithLinkChat.apk.sha256 · checksum file

Requirements

Android 14 or newer (minSdk 34). Not a full ROM — panic wipe and Setup stay on WraithLink Pixel / Lineage images.
