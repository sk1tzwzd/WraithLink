WraithLink

Hardened Android for Pixel. Built on GrapheneOS. Signed with your release keys. Panic wipe that actually destroys encryption keys. No accounts. No telemetry. No marketing theater.

Flash Pixel Documentation

What ships

Lean Pixel image. Features below are real. Milestone work is labeled — not sold as done.

  • Panic wipe

    GrapheneOS duress credential destroys disk keys first, then wipes. Interrupt-resistant.

  • WraithVault

    Secondary user for sensitive apps. Visible profile — backup off-phone. Not deniable storage.

  • Media strip

    GPS, device model, timestamps removed when photos/videos are indexed.

  • Messenger

    E2EE peer-to-peer over Tor. No server. Messages stay in RAM. Download for any Android 14+ phone.

  • Own OTA

    Updater pointed at your domain. Relocked bootloader against the WraithLink key.

  • Setup

    Guided hardening: lock, panic, USB, 2G, Mullvad DNS one-tap, vault.
