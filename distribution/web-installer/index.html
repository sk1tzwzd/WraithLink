WraithLink

Browser-based installer for supported Pixel devices
Before you start
  1. Use a Chromium-based browser (WebUSB is required).
  2. Enable Developer options, then turn on USB debugging and OEM unlocking.
  3. Connect your Pixel by USB and reboot to the bootloader.
  4. Back up your data - installing wipes the device.
Install

Unlocks the bootloader, flashes WraithLink factory images, then relocks against the WraithLink verified-boot key.

Waiting for device...
Security note:

This installer runs entirely in your browser and flashes images signed with the WraithLink release key. Verify the page URL and image checksums against the release notes before flashing.
